# Hsiu-Fang Hsu — Business Analytics portfolio

Personal website: https://hsiufang.github.io

A single-page static site (no build step) hosted on GitHub Pages.

| File | Purpose |
|---|---|
| `index.html` | The whole website (content + styles) |
| `cv.pdf` | CV offered for download (saved as `Hsiu-Fang-Hsu-CV.pdf`) |
| `assets/profile.jpg` | Profile photo (web-sized) |
| `favicon.svg` | Browser tab icon |

## Updating
- **New CV:** recompile `cv.tex`, replace `cv.pdf`, commit and push.
- **Text changes:** edit `index.html` and push. The site updates in ~1 minute.
